# Code of Conduct

## Our commitment

We want the **AI Coding Stack — OmniRoute + NVIDIA + OpenCode** community to be welcoming, respectful, technically focused, and useful to people with different backgrounds and levels of experience.

Everyone participating in this repository is expected to help keep discussions constructive and professional.

## Expected behavior

Examples of behavior that supports a healthy community include:

- Be respectful and patient, especially when people are debugging unfamiliar tools.
- Critique ideas, configurations, and code — not people.
- Give reproducible technical context when reporting a problem.
- Assume good faith while still asking for evidence when claims are technical.
- Respect privacy and never pressure anyone to share credentials, private logs, personal data, or proprietary code.
- Clearly distinguish tested behavior from assumptions, benchmarks, or opinions.
- Accept reasonable maintainer decisions about scope, duplication, safety, and project direction.

## Unacceptable behavior

The following are not acceptable in project spaces:

- Harassment, threats, intimidation, discriminatory language, or personal attacks.
- Sexualized language or unwanted sexual attention.
- Deliberate disruption, spam, trolling, or repeated bad-faith argument.
- Publishing another person's private information without permission.
- Posting secrets, API keys, access tokens, passwords, private keys, or confidential material.
- Encouraging unsafe credential handling, malicious use, or behavior intended to compromise another system.
- Impersonating maintainers, contributors, providers, or partner organizations.

## Technical discussion standards

This repository documents a fast-moving AI tooling stack. Disagreement about providers, models, benchmarks, reliability, cost, or architecture is normal.

Please keep technical claims grounded. When possible, include versions, commands, logs with secrets redacted, reproduction steps, and whether a result was personally tested or only observed in upstream documentation.

## Scope

This Code of Conduct applies to repository Issues, Pull Requests, Discussions, project documentation, and other official collaboration spaces associated with this project.

## Reporting conduct problems

If you experience or witness behavior that violates this Code of Conduct, contact the repository maintainers privately whenever possible. Do not publish sensitive personal information in a public Issue.

Reports should include enough context for the maintainers to understand what happened, while avoiding unnecessary disclosure of private information.

For security vulnerabilities or exposed credentials, follow [SECURITY.md](SECURITY.md) instead of opening a public conduct report.

## Enforcement

Maintainers may edit or remove comments, reject or close contributions, restrict participation, or block users when necessary to protect the community and project.

Enforcement decisions will consider context, severity, repetition, impact on others, and whether the participant cooperates with reasonable requests to stop problematic behavior.

Good-faith mistakes can usually be corrected. Repeated harassment, threats, doxxing, credential exposure, or deliberate abuse may result in immediate removal from project spaces.

## Attribution

This policy is informed by common open-source community standards, including the Contributor Covenant, and adapted for the security and privacy needs of an AI developer-tooling repository.
